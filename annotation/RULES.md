# Правила разметки планировок

Правила для разметки `dataset/` (411 планировок из 7 ЖК с наш.дом.рф) под модель, которая находит проёмы, мебель и сантехнику на чертеже.

Решения по значкам приняты по [справочнику значков](https://claude.ai/artifact/3HABrPEHbvxeX1TtXXBUV1) 21.10.2026. Из 167 карточек 63 отмечены явно. Остальные 104 приняты с предложенным классом:
- 100 уверенных — по умолчанию;
- пунктирный крест (ЖК 56842) и вентшахта (ЖК 61276) — так же, как те же значки, подтверждённые в других ЖК;
- 2 карточки остались без ответа — см. «Открытые вопросы».

## Общие правила

- Рамка прямоугольная, по осям картинки (формат YOLO bbox).
- Размечается каждый отдельный предмет: четыре стула у стола — четыре рамки `chair`, плюс одна `table`.
- Рамки разных объектов могут перекрываться (штора внутри рамки окна, тумбочка рядом с кроватью).
- Не размечаются: цифры площадей, подписи комнат, пунктирные границы зон, размерные линии.

## Окна и двери

Имена классов совпадают с фильтрами в `application/static/js/builder.js`, менять их нельзя.

| Класс | Что это | Как обводить |
|---|---|---|
| `window` | Окно, включая наружное остекление лоджий и балконов, длинное (витражное) остекление и окна на скошенных стенах | На всю толщину прилегающей стены, от наружного края до внутреннего. По длине — по проёму между простенками |
| `window-block` | Балконный блок: окно + дверь на лоджию, двойная линия между комнатой и лоджией | Как окно |
| `door box` | Проём двери в стене | По ширине проёма, на всю толщину стены |
| `door arch` | Дуга открывания вместе с полотном | По дуге и полотну, без проёма в стене |

Каждая дверь даёт две рамки: `door box` и `door arch`. Одна общая рамка ломает `builder.js`: он заливает `door box` стеной и вырезает по нему проём, а `door arch` стирает из стен.

## Мебель

| Класс | Значки |
|---|---|
| `sofa` | Диван по сплошному контуру. Пунктирный прямоугольник рядом с диваном — диван в разложенном виде, отдельно не размечается |
| `armchair` | Кресло, в том числе круглое |
| `bed` | Кровать, одно- и двуспальная одним классом, по контуру с подушками |
| `nightstand` | Тумбочка у кровати: пустой прямоугольник, квадрат с кругом, круг с треугольником (лампа) |
| `chair` | Стул, каждый отдельно |
| `table` | Обеденный стол без стульев |
| `coffee_table` | Журнальный или приставной столик: два круга разного размера, круглый столик с предметами, пустой круг в комнате, маленький круг с точкой, овальный столик |
| `desk` | Письменный стол (стул у него — отдельная рамка `chair`, если нарисован) |
| `wardrobe` | Гардероб: штанга с вешалками (штриховка «ёлочкой») |
| `cabinet` | Закрытый шкаф: прямоугольник со сплошным или пунктирным крестом, в том числе в санузле |
| `tv_stand` | Узкая тумба или стеллаж, на котором стоит ТВ |

| `bench` | Банкетка или пуф: прямоугольник с точками |
| `rug` | Ковёр с волнистым контуром или бахромой (ЖК 61276). Тонкий прямоугольник вокруг зоны мебели (ЖК 70198) не размечается |
| `curtain` | Штора: волнистая линия или пунктир с завитками под окном |
| `plant` | Растение |

Приборы внутри гарнитура размечаются отдельно и перекрываются с рамкой `kitchen_unit`.

## Служебные классы

Размечаются, но в обучение не идут.

- `unknown`: значок есть, смысл неизвестен. Сейчас это:
  - маленький крестик в модуле кухни (ЖК 68781, 69431);
  - круг в прихожей (ЖК 68781, 69431);
  - круг со спицами в квадрате с крестом (ЖК 70198).

  Такие рамки сохраняются, чтобы потом переназначить класс без повторной разметки.
- Зелёные кольца на столе (ЖК 56269) — посуда. Не размечаются.

## Сомнительные места

Спорные объекты не угадываются молча, а записываются в `annotation/doubts.csv`: файл, класс, рамка, причина. Обязательно туда попадают:

- окна на скошенных стенах (ЖК 56842, 68781): рамка выходит почти квадратной, и `builder.js` определяет направление стены по пропорции рамки (`w >= h`) ненадёжно;
- узкие окна в толстой стене, где рамка выше, чем шире, по той же причине;
- значки, которых нет в этом файле.

## Хранение и экспорт

- Разметка хранится рядом с картинкой: `dataset/<ЖК>/<id>.labels.json`, с именами классов и рамками в пикселях исходной картинки.
- Для обучения разметка экспортируется в YOLO по списку классов из `annotation/classes.yaml`. `unknown` и неразмечаемые объекты в экспорт не попадают.
- Битый файл `dataset/68781/…2A71B76B….jpg` (внутри HTML вместо картинки) пропускается.
- Для честной проверки качества в валидацию уходят целые ЖК, а не случайные картинки.

## Открытые вопросы

1. Трапеции у наружной стены (ЖК 56269) — радиаторы? Пока не размечаются, класс `radiator` не заведён.
2. Пустой прямоугольник у изголовья (ЖК 56269) — по умолчанию `nightstand`, явного ответа нет.
3. Пунктирный прямоугольник у дивана я понял как разложенный диван и не размечаю его. Если нужен отдельный класс — его надо завести.
4. Наружное остекление лоджий размечается как `window`. `builder.js` будет вырезать по нему проём в стене лоджии, как в обычной стене.
5. Квадрат с крестиком и точкой в прихожей (ЖК 61276, почти в каждой планировке) — щиток, люк или трап? Пока не размечается.
6. Угловое остекление без простенка (ЖК 61276) размечено отдельной рамкой `window` на каждый отрезок стены.
7. Раздвижные двери санузлов (ЖК 56269, линия со стрелкой вместо дуги) размечены только рамкой `door box`, без `door arch`. Поэтому `check.py` показывает для 56269 непарные двери — 26 планировок, все записаны в `doubts.csv`. Нужен ли отдельный класс или своя «дуга» для раздвижной двери?
8. Раздвижные перегородки между гостиной и кухней (ЖК 68781) не размечены.
9. Диагональное остекление лоджий и комнат (ЖК 68781) размечено одной рамкой `window` по диагонали — рамка почти квадратная, направление стены по ней не определить.
10. Прямоугольник с сеткой квадратов или низкая тумба с тапочками в прихожей (ЖК 67276) размечены как `bench`.
11. Тёмная рамка с белым центром у начала кухни и в санузлах (ЖК 68781) размечена как `shaft`, по правилу для вентшахт.

Вопросы по конкретным объектам собраны в `annotation/doubts.csv`.
